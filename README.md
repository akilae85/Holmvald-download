# Holmvald – download

Qui ci sono le versioni pubblicate di **Holmvald**: le trovi in [Releases](https://github.com/akilae85/Holmvald-download/releases).

- **Per giocare:** scarica `Holmvald-vX.Y.Z-windows.zip`, estrai la cartella e avvia `Holmvald.exe`.
- **Per ospitare una partita multigiocatore:** scarica `HolmvaldServer-vX.Y.Z-windows.zip`, estrai e avvia `HolmvaldServer.exe` (istruzioni nel file `LEGGIMI.txt`).

Il gioco e il server controllano da soli questa pagina all'avvio e, se c'è una versione nuova, si aggiornano e si riavviano.
